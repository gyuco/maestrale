# Prototipo Copernicus (non operativo)

Questa directory conserva il primo esperimento basato su subset NetCDF del
Copernicus Marine Service. Non e importata dal backend, non alimenta
`data/forecasts.json` e non viene eseguita dal job schedulato.

La pipeline operativa usa le sorgenti dichiarate in `../../data_sources.py`.
I file NetCDF generati dal prototipo sono stati rimossi perche obsoleti.
