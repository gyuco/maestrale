# Prototipo Copernicus (non operativo)

Questa directory conserva il primo esperimento basato su subset NetCDF del
Copernicus Marine Service. Non e importata dal Worker, non alimenta
la cache KV e non viene eseguita dal job schedulato.

La pipeline operativa usa le sorgenti dichiarate in `../../worker/src/data_sources.ts`.
I file NetCDF generati dal prototipo sono stati rimossi perche obsoleti.
